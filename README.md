# Калькулятор перекупства

Десктопное приложение для Windows на Python и CustomTkinter. Рассчитывает
расходы, чистую прибыль, маржинальность и ROI, сохраняет последние расчёты и
содержит отдельное окно мониторинга цен маркетплейса через API.

## Возможности

- расчёт прибыльности сделки;
- проверка введённых значений;
- история последних пяти расчётов;
- восстановление последнего результата;
- тёмная тема и прокручиваемая форма;
- мониторинг минимальной, средней и максимальной цены предметов;
- поиск по названию и ID;
- локальное избранное для ID предметов;
- локальный кэш последнего успешного ответа API.

## Установка на Windows

1. Установите Python 3 с сайта <https://www.python.org/downloads/>.
2. Запустите `install.bat` для установки CustomTkinter.
3. Запустите приложение через `start.bat`.

Ручной запуск:

```powershell
python -m pip install -r requirements.txt
python calculator_reselling.py
```

## Мониторинг цен

Нажмите «Мониторинг цен» в главном окне и заполните:

- полный URL endpoint, например
  `https://api.example.com/v1/ext/marketplace/items/RU1`;
- API-ключ;
- тип авторизации: `Bearer`, `X-API-Key` или без авторизации.

API-ключ используется только в памяти и не сохраняется на диск. Файлы истории,
кэша и избранного создаются рядом с программой и исключены из Git.

## Формат ответа API

Программа ожидает массив `itemStatistics` в корне ответа или внутри `data`,
`result`, `response` либо `payload`. Также поддерживается массив предметов,
возвращённый непосредственно в `result`.
