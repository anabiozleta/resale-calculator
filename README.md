# Калькулятор перекупства

Десктопное приложение для Windows для учёта перепродаж, мониторинга цен и
аренды автомобилей. Интерфейс построен на Python и CustomTkinter, а все рабочие
данные сохраняются локально на компьютере пользователя.

## Разделы приложения

### Перепродажа

- создание активного лота по названию предмета и цене покупки;
- отметка «Прямая продажа» для сделки без комиссии;
- сохранение непроданных лотов между запусками;
- выбор лота в правой колонке и ввод цены продажи;
- автоматический расчёт комиссии, расходов, чистой прибыли, маржи и ROI;
- сводка чистого дохода, совокупного ROI и оборота;
- журнал завершённых продаж;
- удаление отдельной продажи и полная очистка журнала.

### Прайс-лист

- получение статистики маркетплейса через API;
- поддержка Bearer, X-API-Key и запросов без авторизации;
- таблица минимальных, средних и максимальных цен;
- поиск по названию и ID предмета;
- локальное избранное для нужных ID;
- локальный кэш последнего успешного ответа;
- поддержка ответов с `itemStatistics` в корне либо внутри `data`, `result`,
  `response` и `payload`.

API-ключ используется только в памяти приложения и не записывается на диск.

### Аренда авто

- добавление автомобилей в автопарк;
- почасовой или посуточный тариф;
- выбор срока публикации объявления;
- ручная настройка стоимости объявления;
- отображение тарифа и статуса автомобиля в автопарке;
- раскрытие карточки автомобиля по клику;
- ввод количества часов или суток непосредственно в карточке;
- автоматический расчёт дохода по формуле `тариф × длительность`;
- журнал только завершённых аренд;
- сводка чистого дохода, расходов на объявления и количества сделок;
- вертикальная прокрутка раздела.

### Настройки

- единая комиссия с продажи от 0 до 100%;
- сохранение комиссии между запусками;
- автоматическое применение комиссии при продаже обычного лота;
- игнорирование комиссии для лотов с отметкой «Прямая продажа».

## Установка на Windows

Рекомендуемый вариант — скачать установщик из раздела
[Releases](https://github.com/anabiozleta/resale-calculator/releases):

1. Скачайте `ResaleCalculator-Setup.exe` из последнего релиза.
2. Запустите установщик.
3. При необходимости включите создание ярлыка на рабочем столе.
4. Запускайте приложение из меню «Пуск» или через созданный ярлык.

Python и дополнительные библиотеки для установленной версии не требуются.
Установщик также регистрирует стандартное удаление приложения в Windows.

> Приложение не подписано коммерческим цифровым сертификатом. Windows SmartScreen
> может показать предупреждение. Используйте файл только из официального Release
> этого репозитория.

## Запуск из исходного кода

Требуется Python 3.

```powershell
python -m pip install -r requirements.txt
python calculator_reselling.py
```

В Windows также можно запустить `install.bat`, а затем `start.bat`.

## Локальные данные

Рядом с программой автоматически создаются:

- `active_lots.json` — непроданные лоты;
- `calculation_history.json` — завершённые перепродажи;
- `app_settings.json` — комиссия и настройки;
- `marketplace_cache.json` — кэш API;
- `marketplace_favorites.json` — избранные ID;
- `rental_data.json` — автопарк и журнал аренды.

Эти файлы исключены из Git. API-ключи также не включаются в репозиторий.

## Сборка EXE

```powershell
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --clean --onefile --windowed `
  --name ResaleCalculator --collect-data customtkinter calculator_reselling.py
```

## Сборка установщика

Для сборки используется Inno Setup 6:

```powershell
& "$env:LOCALAPPDATA\Programs\Inno Setup 6\ISCC.exe" installer.iss
```

Результат создаётся в `installer-output/ResaleCalculator-Setup.exe`.

## Конфиденциальность

Приложение не использует облачное хранилище. Интернет требуется только для
явного запроса пользователя к API в разделе «Прайс-лист».
